HEC-RAS principle used here

We do not run the USACE HEC-RAS binary. We run the first equations it uses.

Q = (1/n) A R2/3 S1/2 (Manning). Normal depth y is solved so computed Q matches GloFAS discharge. Water-surface elevation WSE = zmin + y. A cell is wet if terrain z < WSE.

GLOF peak screen: Qpeak ≈ released volume / breach duration. That is a volume-time weir screen, not a 15-day monsoon hydrograph.
