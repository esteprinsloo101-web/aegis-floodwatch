# AEGIS Floodwatch

Live multi-hazard screening map.

**Public URL:** https://esteprinsloo101-web.github.io/aegis-floodwatch/

- Map, public alerts, Get-me-to-safety, follow-me, and routing are **free**.
- Science Desk (Manning / GloFAS / FWI / Omori / tsunami travel) is **R89 / month** via Payoneer.
- Not an official warning service.

If the map is a black box on a phone, hard-refresh. The map pane is `flex:1` with `100dvh` so tiles fill the screen.
